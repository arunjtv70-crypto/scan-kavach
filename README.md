# Scam Kavach

**AI scam shield for Indians.** Scan a suspicious message or screenshot, get a clear verdict in simple Hindi or English, and get instant help if you have already been scammed.

**Live demo:** <APNA-VERCEL-LINK>

Built for HackIndia 2026 (Open Problem Statement: build an AI-first startup).

---

## The Problem

Every day, Indians lose money to digital arrest calls, fake KYC and UPI messages, phishing SMS, job and investment fraud, identity theft and sextortion. Most victims are not careless. They are scared, rushed, or cannot tell a real bank message from a fake one. Most existing tools work only in English, or help only after the money is gone.

## What Scam Kavach Does

- **Scan:** paste a message or upload a screenshot. Get a verdict (Safe, Suspicious, Scam), a risk score, the exact reasons, and what to do next.
- **Honest by design:** every result also lists what the app could *not* verify (for example where a link leads), so genuine bank alerts are not wrongly called scams.
- **Six scam categories:** UPI and banking, digital arrest and extortion, phishing / vishing / smishing, identity and document fraud, job and investment fraud, sextortion and cyberbullying. Also detects fake client / overpayment scams.
- **Instant Help:** tap-to-call national cyber helpline **1930**, the official cybercrime portal, and category-specific support. Bank fraud contacts come from a fixed, manually verified directory, never generated by AI.
- **Rescue Mode ("Mere saath scam ho gaya"):** for people who have already been scammed. Choose what happened and get a prioritized action plan for the critical first hour, a complaint draft for cybercrime.gov.in and a bank freeze letter.
- **Bilingual:** full Hindi and English interface, and AI explanations in the language the user selects.
- **Sensitive cases handled gently:** sextortion and cyberbullying results use a calm, non-blaming tone, with guidance to preserve evidence and trusted support resources.

> Scam Kavach cannot recover lost money. It helps people act fast and in the right order, and the speed of reporting is what matters most.

## How It Works

1. **Rule engine (code):** extracts hard signals from the message (OTP or PIN requests, money or fee requests, suspicious links, threats, fake authority, urgency, and so on) and decides the risk score and verdict.
2. **AI layer (Groq):** reads screenshots and explains the verdict in simple language. The AI explains; it does not override the rule-based verdict.
3. **Helpline directory:** fixed list of official numbers and portals shown by category and detected bank.

This hybrid design keeps results consistent and reduces false alarms and AI hallucinations.

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js (App Router), TypeScript |
| Styling | Tailwind CSS v4 |
| AI | Groq API (OpenAI-compatible endpoint) |
| Backend | Next.js Route Handlers (`/api/scan`, `/api/rescue`, `/api/health`) |
| Hosting | Vercel |

No database and no user accounts. Messages are processed per request and are not stored.

## Local Setup

**Prerequisites:** Node.js 18 or newer, and a free Groq API key from [console.groq.com](https://console.groq.com).

```bash
# 1. Install dependencies
npm install

# 2. Create your environment file
cp .env.example .env.local
```

Open `.env.local` and add:

```env
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=your_groq_model_name
```

```bash
# 3. Run the app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Check that the AI connection works at `http://localhost:3000/api/health`.

## Deploy on Vercel

1. Push this repository to GitHub.
2. In [Vercel](https://vercel.com), click **Add New Project** and import the repository.
3. Open **Settings, Environment Variables** and add `GROQ_API_KEY` and `GROQ_MODEL` (name and value in separate fields).
4. Deploy. After changing variables, redeploy so they take effect.

Never commit `.env.local` or any API key. It is already listed in `.gitignore`.

## Responsible Use

Scam Kavach gives guidance, not legal or financial advice, and no tool can be 100% accurate. If you suspect fraud, call **1930** or report at [cybercrime.gov.in](https://cybercrime.gov.in), and always confirm with your bank through its official app or the number printed on your card.
